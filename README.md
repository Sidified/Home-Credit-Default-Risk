# Home Credit Default Risk

End-to-end machine learning project on the Home Credit Default Risk dataset.

## Goal

Predict the probability that a loan applicant will have difficulty repaying a loan.

## Project Structure

```text
home-credit-default-risk/
├── data/
│   ├── raw/
│   └── processed/
├── notebooks/
├── src/
├── models/
├── reports/
│   └── figures/
├── tests/
├── requirements.txt
└── README.md
Approach

The project will begin with application_train.csv and build a complete
baseline pipeline before introducing additional tables, feature engineering,
and more advanced models.

Each major improvement will be evaluated against a fixed validation strategy
to measure whether the added complexity actually improves performance.

Dataset

Home Credit Default Risk — Kaggle competition dataset.

The raw dataset is not included in this repository because of its size.

Status

Project in progress.
